### What This PR Does (Plain Language)
This PR adds a benchmark task where an agent must debug a broken equity execution-ledger reconciler. The agent has to process order replacement chains, fills, fees, a stock split, broker positions, and reconciliation rules to produce correct ending positions, PnL, fees, and a break report.

Review focus: under Harbor, visible tests are not treated as leakage blockers when agents cannot access `/tests` at runtime. The real review questions here are difficulty calibration, model discrimination, and whether the verifier failure path behaves reliably.

File: PR description

Suggested fix: if possible, add one stronger failure case showing a capable model failing on the accounting logic itself rather than on schema misunderstanding.
