### What This PR Does (Plain Language)
This PR adds a benchmark task where an agent must migrate a script from one Polars API style to another and preserve the expected staged outputs. In plain terms, the agent is performing a focused code-migration exercise rather than a deep financial-analysis task.

Review focus: the main questions here are difficulty calibration and benchmark value. A deterministic migration task can be valid, but the claimed difficulty has to match what the task is actually asking the agent to do.

- Rechecked the earlier conclusions with focus on task difficulty, anti-overfitting posture, and grading reliability.
- Preserved the core judgment that this looks much easier than the claimed level.

### A. Structural Completeness — 7/10
The task is concrete and deterministic. As a migration exercise, it is easy to understand.

### B. Task Contract & Determinism — 8/10
The task goal is narrow and specific, which makes it straightforward to grade reproducibly.

### C. Difficulty Calibration & Model Signal — 2/10
**[MAJOR] This does not look like a meaningful medium benchmark task**  
The prior review notes indicate the API mapping is explicit, the required output is narrow, and the verifier compares against fixed known stage outputs. That looks much closer to an easy migration exercise than a meaningful medium benchmark item.

Suggested fix: downgrade the difficulty label unless the author can provide strong contrary evidence.

**[MAJOR] Hardcoding / overfitting resistance looks weak**  
The task shape, dataset, staged outputs, and reference artifacts appear fixed enough that an agent can optimize toward them fairly directly.

Suggested fix: strengthen the anti-overfitting posture if the task is meant to carry benchmark weight beyond a simple migration check.

### D. Evaluation Criteria & Grading Reliability — 4/10
**[MAJOR] Verifier failure handling is reportedly still brittle**  
The prior review notes indicate `tests/test.sh` uses the fragile `$?` pattern after the main command rather than an explicit `if ...; then ... else ... fi` wrapper.

Suggested fix: rewrite the shell wrapper in explicit form so reward emission is reliable.

### Summary
This task may be useful as a deterministic migration exercise, but it does not currently look like a credible medium benchmark item. The main problem is not ambiguity, it is that the claimed challenge level appears too high for the actual work required.
