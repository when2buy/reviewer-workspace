### What This PR Does (Plain Language)
This PR adds a benchmark task where an agent must estimate an EWMA covariance matrix from ETF return data, decompose portfolio risk into marginal and component contributions, and compute parametric Value at Risk. In plain terms, the agent has to turn raw return history and portfolio weights into a complete risk report.

Review focus: the important questions here are whether the task contract is internally consistent, whether the financial computations are correctly specified, and whether the grading behavior is reliable under the actual Harbor execution model. Under that model, agents do not get access to `/tests` at runtime, so visible verifier code is not treated as a leakage blocker in this review.
