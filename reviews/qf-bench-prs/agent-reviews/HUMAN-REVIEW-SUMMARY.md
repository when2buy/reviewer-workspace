# Human-Review Supplement — PQCat (2026-04-26)

This file complements [`FINAL-SUMMARY.md`](FINAL-SUMMARY.md) (zhikang's full review) with an independent re-test of 18 QF-Bench PRs against fresh `harbor` agent runs — Haiku 4.5, Sonnet 4.6, and Opus 4.6 where it adds signal.

## What this review found

The 18 PRs cluster into three patterns:

1. **Strong content, mergeable as-is or with light wording fixes.** Tasks whose financial methodology is sound, whose tests cleanly discriminate by capacity, and where the agents' failures (when present) point at real options/credit/factor-model intuition rather than spec-guessing.

2. **Spec ambiguities or convention mismatches.** Tasks where the instruction's wording leaves a real methodology choice unspecified, while the test pins exactly one of the equally-defensible readings. Agents who pick the "wrong" side of an ambiguity are penalized for a guessing game, not a knowledge gap. These need instruction-tightening before they can fairly grade capability.

3. **Easy but content-essential.** Tasks where all three Claude tiers pass cleanly with bit-identical outputs — no capacity discrimination — but the underlying topic is important and not covered by anything else in the existing merge-recommended set. These are recommended for **merge** despite low difficulty, on coverage grounds:
   - **PR #172** `merton-jump-diffusion` — Merton 1976 jump-diffusion MLE + series option pricing + smile diagnostic.
   - **PR #125** `bl-regime-hmm` — only Baum-Welch / hidden-state-estimation task in the entire 105-PR review.
   - **PR #119** `option-put-call-parity-forward-audit` — only put-call-parity arbitrage / market-microstructure / quote-side options task.

## Conventions

- Cell format: `✓ N/M` (pass) or `✗ N/M` (fail), where N/M = tests passed / total.
- All runs use the latest version of the model in question via the `harbor claude-code` agent.
- Reward is binary unless the task uses a graded verifier (e.g. `barra-cne6-risk`, `merton-cds-copula`, `bl-regime-hmm` — these report partial credit / PERFECT-IMPERFECT-WRONG).

## Methodology

- Each agent run is a fresh Claude Code session; no shared context across runs.
