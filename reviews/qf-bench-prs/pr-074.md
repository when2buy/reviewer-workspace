### What This PR Does (Plain Language)
This PR adds a benchmark task where an agent must implement a Black-Litterman asset-allocation workflow: infer equilibrium returns from market-cap weights, apply investor views, compute posterior returns, and optimize portfolios under long-only constraints. In plain terms, the agent has to turn ETF price history plus a set of market views into several portfolio recommendations and compare them.

Review focus: the key questions here are difficulty calibration, empirical validation quality, and whether the grader behaves reliably. Under Harbor, visible tests are not treated as leakage blockers when agents cannot access `/tests` at runtime.
